# AGENTS.md - 电子书阅读器项目说明

## 项目是什么
这是一个纯前端的网页版 TXT 电子书阅读器，用户可以上传本地 TXT 文件，在网页上分页阅读，支持调节字号、行间距，自动记忆阅读进度。

## 技术栈
- 原生 HTML + CSS + JavaScript，不需要任何框架
- 纯静态页面，不需要构建工具
- 浏览器原生 API：FileReader、localStorage

## 目录结构
```
电子书阅读器/
├── index.html          # 主页面
├── style.css           # 样式文件
├── app.js              # 主逻辑
├── PRD.md              # 需求文档
├── TECH_DESIGN.md      # 技术设计文档
└── AGENTS.md           # 本文件
```

## 怎么跑起来
直接用浏览器打开 index.html 就行，不需要安装任何依赖，不需要启动服务器。

如果要部署到 GitHub Pages，把整个文件夹推送到 GitHub 仓库，然后开启 GitHub Pages 即可。

## 硬性约定
1. **纯前端实现**：所有逻辑都在浏览器端，不依赖任何后端服务
2. **本地处理**：文件只在本地解析，不上传到任何服务器，保护用户隐私
3. **无依赖**：不引入任何第三方库，用原生 API 实现
4. **响应式**：适配不同屏幕尺寸，手机和电脑都能用

## 开发注意事项
1. 分页计算要动态算，不能写死每页多少行，因为字号和行间距是可调的
2. 阅读进度和设置要存到 localStorage，刷新后能恢复
3. 文件上传只支持 TXT 格式，UTF-8 编码
4. 界面要简洁，适合长时间阅读
